# Presentación SendPulse — código legible

Abre esta carpeta completa en VS Code. Puedes abrir index.html directamente en el navegador.

## Archivos

- index.html: textos y estructura. Cada diapositiva está marcada con un comentario.
- styles.css: colores, tamaños, distribución y animaciones.
- script.js: ventanas emergentes, navegación, guion y editor. Busca `details` para cambiar el contenido de las ventanas y `notes` para cambiar el guion.
- images/: imágenes PNG originales, sin convertirlas en cadenas de texto.

## Cambiar una imagen

Reemplaza su archivo dentro de images conservando el nombre, o cambia la ruta en index.html y/o script.js. Algunas imágenes aparecen en ambos archivos.

Ejemplo: `<img src="images/joomla.png" alt="Editor de Joomla">`.

## GitHub

Sube index.html, styles.css, script.js y la carpeta images juntos. Conserva los nombres y las rutas.

## Editor visual incluido

El botón Descargar cambios genera un HTML modificado que sigue utilizando styles.css, script.js e images/. Guarda esa descarga en esta misma carpeta. Las imágenes nuevas cargadas desde el editor visual se incrustan en esa descarga; para mantener el código limpio, cambia las imágenes desde la carpeta images y sus rutas.

Esta entrega organiza el código y extrae las imágenes. No modifica los textos de la presentación ni corrige las diferencias de contenido señaladas respecto al Genially.
